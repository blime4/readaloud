# ReadAloud · 朗读工作台

把任意文字读给你听 —— 语音合成用微软 Edge 神经语音，总结与润色用**你这台电脑上的 Ollama 模型**。
文字不出本机，AI 也在本机跑。

工作台页面可以放在 GitHub Pages 上，用任何设备打开都行；但它连的永远是**你本地那台机器**的引擎。

## 三种用法

| 场景 | 怎么用 |
| --- | --- |
| 网页 | 把链接粘进「读网页」输入框 → 自动抓正文开读。也可以直接把链接粘进文稿框再点朗读 |
| Obsidian | 插件 `readaloud-bridge`：选中文字 `Ctrl+Alt+P` 朗读，`Ctrl+Alt+O` 读整篇，`Ctrl+Alt+S` 总结后朗读 |
| 任意软件 | `Ctrl+Alt+R` 读剪贴板（**内容是链接就自动抓网页正文**）、`+E` 读当前选中的文字、`+S` 总结后读、`+W` 润色后读、`+X` 开工作台、`+Q` 停止 |

## 贴个链接就能听

贴链接 → 抓正文 → 开读，默认 **0.2~1 秒**（走规则抓取，不动用模型）。
抓完会在输入框下方摊开一份诊断：标题、字数、段落数、用了哪条提取路线、清掉多少行网页残留、
抓取质量分（0-100），以及模型做了什么。不用猜"到底抓到没有、抓得对不对"。

- **按原文朗读**，不会偷偷缩成摘要（要摘要点「✨ 总结」）。这点很关键 ——
  "智能模式"原本对长文会自动先总结，贴链接时会把一篇 2400 字的文章压成 170 字，
  用户以为在读文章，其实在听摘要。
- **勾「智能整理」**才唤醒本机小模型，直接对已抓到的稿子做深度清理：
  删掉头尾混进来的导航、推广语、"关注我公众号"、相关文章墙。实测 0.8 秒。
- 微信 / 掘金 / 少数派 / 维基 / 博客 / 英文站都能抓；知乎这类要登录的会**明确告诉你原因**，
  而不是丢一句"抓取失败"，并给一个「🧠 让模型硬试一次」的按钮。
- **本机 / 内网地址（`127.0.0.1`、`192.168.*`、局域网机器名）永远直连**，不走系统代理 ——
  否则代理够不到回环地址，只会回一个 502，把自己起的服务挡在门外。

**模型只在该上场时才上场。** 抓得干净（质量分 ≥65）就直接返回，一点算力都不烧；
抓不到时不空喊模型（换身份重抓撞的是同一堵墙，实测白烧 39 秒），直接如实报错。
只有"抓到了但很脏"或用户要求深度清理时，才交给会调工具的小模型。

> 深度清理走的是**单步**调用（直接 `clean_page`），不绕工具回路 ——
> 清理本来就是一个动作，让模型先"决定去抓"再"决定去清"纯属浪费一轮。

## 它比"能出声"多做了什么

**朗读稿是"洗"过的，不是直接把原文字念出来。**

* 结构感知：先认出标题 / 列表 / 引用 / 代码 / 表格，再决定怎么读 ——
  标题会慢一点、多停一会儿，代码和表格直接跳过，列表一条条念。
* 逐句是真逐句（约 60 字/句），所以高亮跟着声音走，还能做句间停顿；
  标题后停 760ms、段末停 660ms、句间停 330ms —— 不是 mp3 一个接一个无缝连读。
* 读音规整（不开 AI 也生效，零延迟）：
  `2026-10-14` → 2026年10月14日、`62%` → 百分之62、`¥1,280` → 1280元、
  `3.5–4.2` → 3.5到4.2、`v1.1.0` → 版本1.1.0、`HTTP/2` → HTTP 2、
  `（上季度55%）` → 逗号承接（念起来有停顿）、URL → "网页链接"。
* 你还能在 `pronounce.json` 里加自己的发音（`K8s` → `Kubernetes`），改完立刻生效。

**它会挑音色，而不是让你在 66 个里猜。**

按内容推荐：中英夹读用多语种音色、技术稿用沉稳播报音、故事用叙事音、粤语用粤语音色。
不确定就先点「🔈 试听」。

**等待时间被消掉了。**

* AI 结果**落盘缓存**：同一段文字第二次点朗读是 0 秒（实测 34.5s → 0.005s）。
* 长文（> `long_doc_chars`）自动**分块提炼再合并**，避免撞上 8k 上下文被静默截断。
* 「智能」模式：短文直读，长文自动先总结 —— 你只需要点一次朗读。
* 生成过程可取消，进度可见，不再是一块什么都不动的遮罩。

**听感可以随时改，不用从头再听。**

* 改语速/音色/音量**从当前这句生效**，不打断、不回到第一句。
* 底部播放条：上一句 / 播放暂停 / 下一句 / 重读本句 / 停止，进度条可点击跳转，显示剩余时长。
* 定时停止（5/15/30/60 分钟或读完当前段）—— 睡前听。
* 夜间模式、`空格`/`←`/`→`/`Esc` 全键盘操作、最近朗读记录、润色后可一键撤销回原文。

## 安装（一次性）

1. 下载本仓库（`Code → Download ZIP`）解压
2. 双击 **`install.bat`** —— 自动建环境、装依赖、注册 `readaloud://` 协议
3. 完事。之后**所有操作都在浏览器里**：在工作台页面点「一键启动本机引擎」即可

依赖只有 Python 3.10+ 和三个包（`edge-tts`、`flask`、`requests`）。
AI 功能额外需要 [Ollama](https://ollama.com)；没有也能正常朗读，只是「总结 / 润色」不可用。

## 在 GitHub Pages 上用

页面部署在 `docs/`，开启 Pages 后地址形如 `https://<用户名>.github.io/readaloud/`。

从云端页面连本机引擎时，浏览器会问一次是否允许「本地网络访问」（Chrome 142+ 的安全机制）——
**选允许即可**，之后不再打扰。顺手点一下「允许」的代价，换来的是文字和模型全程只在你本机。

## 接口速查

| 接口 | 用途 |
| --- | --- |
| `POST /api/prepare` | 一步到位：清洗 →（可选）AI → 规整 → 逐句。返回 `items[{text,kind,pause,rate}]` + 推荐音色 |
| `POST /api/plan` | 只清洗+规整+逐句，不碰 AI |
| `GET\|POST /api/fetch?url=` | 抓网页正文。返回 `title/text/chars` 外加 `quality`（0-100 质量分）、`route`（用了哪条提取路线）、`dropped`（清掉多少行网页残留）、`diag`（试过哪些策略） |
| `POST /api/agent` | 让会调工具的小模型主导取稿。body：`{url, clean, model, retry}`。先走零模型开销的规则抓取（通常 <1 秒）；抓得够干净就直接返回，彻底抓不到就直接报错（`retry:true` 才让模型硬试）；勾 `clean` 时直接深度清理。返回 `trace` 记录模型每一步动作 |
| `POST /api/ai` | 总结 / 润色（`stream=true` 可流式，结果自动缓存） |
| `GET /api/tts?text=&voice=&rate=&pitch=&volume=` | 直接返回 MP3 |
| `GET /api/recommend` | 按内容推荐音色 |
| `GET\|POST /api/settings` | 记住 AI 偏好（会注入提示词）与朗读选项 |
| `POST /api/broadcast` · `GET /api/events` | 剪贴板/热键 → 已打开的播放页（SSE） |

## 读网页是怎么做的

抓取引擎在 `webfetch.py`。目标不是"把 HTML 转成文本"，而是"还原一份人念得下去的稿子"，
所以要额外解决四件事：

- **编码探测**：很多站点 `Content-Type` 只写 `text/html` 不给 charset，requests 会退回
  ISO-8859-1，中文整段乱码。按「HTTP 头 → meta → 字节猜测」三层定编码。
- **段落重排**：英文站用硬换行排版，一段话被拆成十几行，直接读就是"半句话、停顿、半句话"。
  按句末标点把碎行接回完整段落；标题/引文/列表项则独立成段。
  **顺序不能反**：清噪声要在重排**之前**先做一遍，否则作者卡片、"7 分钟阅读"这类
  又短又没有句读的碎片会被 reflow 粘进正文段落，再也分不开。但重排前只清含中文的行 ——
  英文站的短行是正常的正文碎片。
- **噪声清理**：导航、面包屑、推广语、相关文章墙、二维码提示、作者简介、赞赏按钮文案……
  规则先过一遍，剩下拿不准的交给模型（`/api/agent`）。
- **结构保留**：`<h1>-<h6>` / `<blockquote>` / `<li>` 会转成 `#` / `>` / `-` 标记带下去，
  这样 `text_nlp` 才认得出标题、引文、条目，朗读时才有"标题慢读、条目紧凑、引用留白"的语气分层。
  缩进过的 HTML（`<h1>\n  标题\n</h1>`）会把井号和标题拆成两行，必须粘回去。
  **注意：这条链路中途不能再调 `clean_text`** —— 它会把标记一起洗掉，每篇网页都会退化成
  "全是普通段落"，读着是平的。`selftest_fetch.py` 第 4/6 节专门锁住这两点。
- **代理绕行**：回环 / 内网地址一律不走代理，且在 requests 层面显式关掉 ——
  只传 `proxies=None` 不够，它还会去读环境变量里的 `HTTP_PROXY`，
  把"直连"偷偷变成"走代理"，回环地址就只能拿到一个 502。

模型只在需要时上场：抓得干净（质量分 ≥65）就直接返回，不烧一点算力；
"抓到了但很脏"或用户勾了「智能整理」时才启动模型。**彻底抓不到时不叫模型** ——
auto 模式已经把桌面/手机两种身份都试过，模型再抓撞的是同一堵墙。

给模型挑的是**会调工具但不思考**的模型（`pick_agent_model()` 自动选）。本机的 qwen3 系列
一律带 thinking，做"哪些行是网页垃圾"这种判断时输出只有十来个字符，却要先思考几十秒
（实测 qwen3:4b 清理一次 175 秒，qwen2.5:7b 只要 6 秒，而且判得更准）：

```bash
ollama pull qwen2.5:7b   # 会调工具、不思考，取稿 Agent 用它
```

**提示词里别写否定式约束。** 系统提示里曾有一句「只输出工具调用，不要输出解释性文字」，
结果 qwen2.5:7b 直接吐空回复（连 `tool_calls` 都没有），4 次里 0 次成功；
换成肯定式的「每一轮都调用一个工具，工具调用就是你这一轮的全部回答」后 4/4 成功。
小模型处理"不要做 X"远不如"要做 Y"可靠。

## 自检

```bash
.venv/Scripts/python.exe selftest_nlp.py     # 文本智能层：结构/规整/切句/音色推荐（42 项）
.venv/Scripts/python.exe selftest_fetch.py   # 网页取稿：编码/重排/噪声/结构/真实站点（49 项）
.venv/Scripts/python.exe selftest_fetch.py --offline   # 只跑纯函数，不联网
.venv/Scripts/python.exe _selftest.py        # 端到端：剪贴板/热键/分句/合成/推送
```

## 常见问题

**页面显示「未连接本机引擎」**
先点页面上的「一键启动」。如果没反应，说明协议没注册 —— 双击 `install.bat` 或 `install-protocol.bat`。
实在不行就双击 `start-server.bat` 手动启动，再回页面点「重试」。

**浏览器提示被拒绝访问本地网络**
地址栏左侧图标 → 网站设置 → 把「本地网络访问」改成「允许」→ 刷新页面。

**贴了链接但读出来是摘要 / 内容不对**
抓链接默认按**原文**朗读，不会自动缩成摘要（要摘要点「✨ 总结」）。如果内容不对，
看输入框下方的抓取面板：里面有质量分、用了哪条提取路线、清掉多少行残留。
分数低说明这站点在反爬（知乎、付费墙），把浏览器里看到的正文复制过来一样能读。

**贴链接抓不到**
先看面板里的失败原因。需要登录的页面（知乎、付费内容）抓不到是正常的。
反爬站点会明确告诉你"站点正在做安全检测"或"需要登录"，而不是丢一句"抓取失败"。

**总结/润色很慢**
本机装的 qwen3 系列都带 thinking，思考占了绝大部分时间。想要快就拉个不思考的模型
（`ollama pull qwen2.5:7b`）再选它；想要质量就留着 qwen3。两个模型别同时驻留
（16GB 显存会被挤爆）。

**朗读的发音不对**
改 `pronounce.json`，左边写原文、右边写想读成的样子。改完立刻生效，不用重启。

**edge-tts 报 403**
版本太老。`edge-tts` 需 **7.3.0+**（微软换了鉴权令牌方案），`requirements.txt` 已锁定。

## 端口与配置

默认端口 `8756`，改 `config.json` 里的 `port`；也可用环境变量 `READALOUD_PORT` 覆盖。
换了端口后，改浏览器 localStorage 的 `ra.port`，或改 `config.json` 后重启引擎。

`config.json` 里值得动的几项：`max_len`（单句长度上限，默认 62）、`normalize`（读音规整开关）、
`auto_voice`（按内容推荐音色）、`long_doc_chars`（超过就分块总结）、`prefs.style`（AI 偏好）。

## 目录结构

```
docs/index.html     工作台页面（GitHub Pages 发布的就是它，本地引擎也托管同一份）
server.py           引擎：语音合成 + AI 总结润色 + 缓存 + 播放广播 + 对外接口
webfetch.py         网页取稿：编码探测 / 站点适配 / 段落重排 / 噪声清理 / 质量评分
webagent.py         取稿 Agent：给会调工具的小模型挂 fetch_page / clean_page / finish
text_nlp.py         文本智能层：结构解析 / 读音规整 / 逐句切分 / 音色推荐
launcher.py         readaloud:// 协议的执行端（启动/停止/打开）
setup_protocol.py   注册/注销自定义协议
ra_common.py        剪贴板/选区读取、调用引擎、通知提示
clip_read.py        剪贴板朗读
hotkey.py           全局热键守护
pronounce.json      自定义发音词典（改完立刻生效）
selftest_fetch.py   网页取稿自检（49 项，含真实站点）
install.bat         一键安装
```

## 卸载

- 关服务：`stop-server.bat`
- 注销协议：`uninstall-protocol.bat`
- 取消开机自启：`disable-autostart.bat`
- 删干净：直接删掉整个目录
