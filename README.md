# ReadAloud · 朗读工作台

把任意文字读给你听 —— 语音合成用微软 Edge 神经语音，总结与润色用**你这台电脑上的 Ollama 模型**。
文字不出本机，AI 也在本机跑。

工作台页面可以放在 GitHub Pages 上，用任何设备打开都行；但它连的永远是**你本地那台机器**的引擎。

## 三种用法

| 场景 | 怎么用 |
| --- | --- |
| 网页 | 打开工作台 → 粘贴文稿 → 朗读。逐句高亮、点任一句跳读、段间有停顿 |
| Obsidian | 插件 `readaloud-bridge`：选中文字 `Ctrl+Alt+P` 朗读，`Ctrl+Alt+O` 读整篇，`Ctrl+Alt+S` 总结后朗读 |
| 任意软件 | `Ctrl+Alt+R` 读剪贴板（**内容是链接就自动抓网页正文**）、`+E` 读当前选中的文字、`+S` 总结后读、`+W` 润色后读、`+X` 开工作台、`+Q` 停止 |

## 它比"能出声"多做了什么

**朗读稿是"洗"过的，不是直接把原文字念出来。**

* 结构感知：先认出标题 / 列表 / 引用 / 代码 / 表格，再决定怎么读 ——
  标题会慢一点、多停一会儿，代码和表格直接跳过，列表一条条念。
* 逐句是真逐句（约 60 字/句），所以高亮跟着声音走，还能做句间停顿；
  标题后停 760ms、段末停 660ms、句间停 330ms —— 不是 mp3 一个接一个无缝连读。
* 读音规整（不开 AI 也生效，零延迟）：
  `2026-10-14` → 2026年10月14日、`62%` → 百分之62、`¥1,280` → 1280元、
  `3.5–4.2` → 3.5到4.2、`v1.1.0` → 版本1.1.0、`HTTP/2` → HTTP 2、
  `（上季度55%）` → 逗号承接（念起来有停顿）、URL → "网页链接"。
* 你还能在 `pronounce.json` 里加自己的发音（`K8s` → `Kubernetes`），改完立刻生效。

**它会挑音色，而不是让你在 66 个里猜。**

按内容推荐：中英夹读用多语种音色、技术稿用沉稳播报音、故事用叙事音、粤语用粤语音色。
不确定就先点「🔈 试听」。

**等待时间被消掉了。**

* AI 结果**落盘缓存**：同一段文字第二次点朗读是 0 秒（实测 34.5s → 0.005s）。
* 长文（> `long_doc_chars`）自动**分块提炼再合并**，避免撞上 8k 上下文被静默截断。
* 「智能」模式：短文直读，长文自动先总结 —— 你只需要点一次朗读。
* 生成过程可取消，进度可见，不再是一块什么都不动的遮罩。

**听感可以随时改，不用从头再听。**

* 改语速/音色/音量**从当前这句生效**，不打断、不回到第一句。
* 底部播放条：上一句 / 播放暂停 / 下一句 / 重读本句 / 停止，进度条可点击跳转，显示剩余时长。
* 定时停止（5/15/30/60 分钟或读完当前段）—— 睡前听。
* 夜间模式、`空格`/`←`/`→`/`Esc` 全键盘操作、最近朗读记录、润色后可一键撤销回原文。

## 安装（一次性）

1. 下载本仓库（`Code → Download ZIP`）解压
2. 双击 **`install.bat`** —— 自动建环境、装依赖、注册 `readaloud://` 协议
3. 完事。之后**所有操作都在浏览器里**：在工作台页面点「一键启动本机引擎」即可

依赖只有 Python 3.10+ 和三个包（`edge-tts`、`flask`、`requests`）。
AI 功能额外需要 [Ollama](https://ollama.com)；没有也能正常朗读，只是「总结 / 润色」不可用。

## 在 GitHub Pages 上用

页面部署在 `docs/`，开启 Pages 后地址形如 `https://<用户名>.github.io/readaloud/`。

从云端页面连本机引擎时，浏览器会问一次是否允许「本地网络访问」（Chrome 142+ 的安全机制）——
**选允许即可**，之后不再打扰。顺手点一下「允许」的代价，换来的是文字和模型全程只在你本机。

## 接口速查

| 接口 | 用途 |
| --- | --- |
| `POST /api/prepare` | 一步到位：清洗 →（可选）AI → 规整 → 逐句。返回 `items[{text,kind,pause,rate}]` + 推荐音色 |
| `POST /api/plan` | 只清洗+规整+逐句，不碰 AI |
| `GET /api/fetch?url=` | 抓网页正文（返回 title / text / chars） |
| `POST /api/ai` | 总结 / 润色（`stream=true` 可流式，结果自动缓存） |
| `GET /api/tts?text=&voice=&rate=&pitch=&volume=` | 直接返回 MP3 |
| `GET /api/recommend` | 按内容推荐音色 |
| `GET|POST /api/settings` | 记住 AI 偏好（会注入提示词）与朗读选项 |
| `POST /api/broadcast` · `GET /api/events` | 剪贴板/热键 → 已打开的播放页（SSE） |

## 常见问题

**页面显示「未连接本机引擎」**
先点页面上的「一键启动」。如果没反应，说明协议没注册 —— 双击 `install.bat` 或 `install-protocol.bat`。
实在不行就双击 `start-server.bat` 手动启动，再回页面点「重试」。

**浏览器提示被拒绝访问本地网络**
地址栏左侧图标 → 网站设置 → 把「本地网络访问」改成「允许」→ 刷新页面。

**总结/润色很慢或报错**
两个模型别同时驻留（16GB 显存会被挤爆）。在界面「本机引擎信息」里看看装了哪些模型，
选一个用就好。没有模型时执行 `ollama pull qwen3:4b`。

**朗读的发音不对**
改 `pronounce.json`，左边写原文、右边写想读成的样子。改完立刻生效，不用重启。

**抓网页抓不到正文**
需要登录、或正文由脚本动态加载的页面抓不到（会明确告诉你），手动复制正文即可。

**edge-tts 报 403**
版本太老。`edge-tts` 需 **7.3.0+**（微软换了鉴权令牌方案），`requirements.txt` 已锁定。

## 端口与配置

默认端口 `8756`，改 `config.json` 里的 `port`；也可用环境变量 `READALOUD_PORT` 覆盖。
换了端口后，改浏览器 localStorage 的 `ra.port`，或改 `config.json` 后重启引擎。

`config.json` 里值得动的几项：`max_len`（单句长度上限，默认 62）、`normalize`（读音规整开关）、
`auto_voice`（按内容推荐音色）、`long_doc_chars`（超过就分块总结）、`prefs.style`（AI 偏好）。

## 目录结构

```
docs/index.html     工作台页面（GitHub Pages 发布的就是它，本地引擎也托管同一份）
server.py           引擎：语音合成 + AI 总结润色 + 缓存 + 网页抓取 + 播放广播
text_nlp.py         文本智能层：结构解析 / 读音规整 / 逐句切分 / 音色推荐
launcher.py         readaloud:// 协议的执行端（启动/停止/打开）
setup_protocol.py   注册/注销自定义协议
ra_common.py        剪贴板/选区读取、网页抓取、与引擎通信
clip_read.py        剪贴板朗读
hotkey.py           全局热键守护
pronounce.json      自定义发音词典（改完立刻生效）
install.bat         一键安装
```

## 卸载

- 关服务：`stop-server.bat`
- 注销协议：`uninstall-protocol.bat`
- 取消开机自启：`disable-autostart.bat`
- 删干净：直接删掉整个目录
