文稿 0 字

怎么在别处用？（Obsidian / 快捷键 / 接口）
  • Obsidian：设置 → 第三方插件 → 启用 ReadAloud Bridge，选中文字后按 Ctrl+Alt+P 朗读，Ctrl+Alt+S 总结朗读。
  • 任意软件：复制文字 → Ctrl+Alt+R（朗读剪贴板）/ Ctrl+Alt+S（总结剪贴板再朗读）。页面开着时会直接在这里播出。
  • URL 直达：?text=要读的内容&auto=1，任何能打开链接的程序都能用。
  • 纯音频接口：/api/tts?text=你好 直接返回 MP3，可塞进播放器或下载。
