🔗
怎么在别处用？（贴链接 / Obsidian / 快捷键 / 接口）
  • 读网页：把链接粘到上方输入框就会自动抓正文开读（也可直接把链接粘进文稿框再点朗读）。抓取会还原被网页硬换行切碎的句子，并清掉导航、推广语、相关文章这些残留；标题/条目/引文会按语气分层朗读。
  • 智能整理：勾上后让本机小模型把关 —— 抓不到时换身份重抓，并删掉头尾混进来的网页垃圾。会自动挑"会调工具但不思考"的模型（如 qwen2.5:7b），几秒完成。
  • Obsidian：选中文字后按 Ctrl+Alt+P 朗读，Ctrl+Alt+O 读整篇，Ctrl+Alt+S 总结后读。
  • 任意软件：复制文字或链接 → Ctrl+Alt+R（读剪贴板，是链接就自动抓网页）/ +E（读当前选中的字）/ +S（总结后读）。
  • 键盘：空格 播放/暂停，←/→ 上一句/下一句，Esc 停止。
  • URL 直达：?text=要读的内容&auto=1；?url=https://… 可直接朗读网页正文。
  • 纯音频接口：/api/tts?text=你好 直接返回 MP3。
